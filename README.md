# 🩸 RaktSathi

## Smart Blood Resource Network

**Connecting People. Saving Lives.**

RaktSathi is a healthcare technology prototype designed to help people discover relevant blood resources, raise blood requests, coordinate potential donors, and access blood-safety education through one connected platform.

## 🌐 Core Features

- 🩸 Blood Resource Discovery
- 📍 Nearby Blood Centre Search
- 🆘 Emergency Blood Request
- 🤝 Donor Coordination
- 🏥 Blood Centre Information
- 📚 Blood Donation & Safety Education
- 🤖 Healthcare Assistant
- 📱 Responsive Web Experience
- 🗺️ Location-Based Discovery

## 🎯 Vision

To make blood-resource discovery faster, simpler and more accessible by connecting people with relevant authorized healthcare resources.

## 🔐 Safety & Responsibility

RaktSathi does not store, test, transport, release or distribute blood.

Actual blood collection, testing, compatibility assessment, storage and release are performed by authorized blood centres and healthcare facilities according to applicable medical protocols.

RaktSathi is a technology-based discovery and coordination prototype and does not guarantee blood availability.
